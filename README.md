# AI Repository Analyzer & PR Reviewer

Автоматизована утиліта для комплексного аналізу коду репозиторію та автоматичного рев'ю Pull Request-ів за допомогою моделі **Gemini 2.5 Flash**.

## 🚀 Функціонал
1. **Повний аналіз репозиторію:** опис архітектури, використовуваних технологій, сильних сторін, виявлених проблем та детальних рекомендацій.
2. **Автоматичне рев'ю PR (Бонусне завдання):** отримання змін через GitHub API, аналіз diff-файлу на предмет багів, архітектурних зауважень, оптимізації продуктивності та генерація детального Markdown-звіту.

## 🛠 Налаштування
Перед запуском експортуйте ваші API токени:
```bash
export GEMINI_API_KEY="ваш_gemini_ключ"
export GITHUB_TOKEN="ваш_github_token" # Обов'язково для приватних репозиторіїв або частих запитів
```

## 💻 Використання

### 1. Повний аналіз коду (Основне завдання)
```bash
python3 cli.py <owner/repository> [назва_гілки]
# Результат збережеться у файл: output/report.md
```

### 2. Рев'ю змін у Pull Request (Бонусне завдання)
```bash
python3 cli.py <owner/repository> --pr <номер_pr>
# Результат збережеться у файл: output/pr_review.md
```
